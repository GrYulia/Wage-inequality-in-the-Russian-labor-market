# Wage-inequality-in-the-Russian-labor-market
Данный проект представляет собой полный цикл эконометрического и машинного исследования факторов, определяющих уровень заработной платы в России, с фокусом на количественную оценку гендерного разрыва. В основе — микроданные 32-й волны Российского мониторинга экономического положения и здоровья населения.
